🔒 Politique de Confidentialité

Tano Evoluzione - Système de Gestion d'Atelier Automobile

Date de dernière mise à jour : 22 décembre 2024

En bref : Tano Evoluzione respecte votre vie privée. Toutes vos données restent sur votre appareil. Nous ne collectons, ne vendons, ni ne partageons aucune donnée personnelle.

1. Introduction

Bienvenue sur Tano Evoluzione. Cette politique de confidentialité explique comment notre application mobile traite vos informations. Nous nous engageons à protéger votre vie privée et à être totalement transparents sur l'utilisation des données.

2. Données Collectées

2.1 Données saisies par l'utilisateur

L'application vous permet de saisir volontairement les informations suivantes :

  • Informations des véhicules : Plaque d'immatriculation, marque, modèle, année, VIN, kilométrage
  • Informations des clients (optionnelles) : Nom, email, téléphone
  • Détails des interventions : Date, type, description, pièces utilisées, coût, notes techniques
  • Photos : Photos des interventions mécaniques que vous choisissez d'ajouter
  • Informations de paiement : Statut (payé/non payé/partiel) et dates de paiement

2.2 Stockage des données

Important : Toutes les données que vous saisissez sont stockées exclusivement sur votre appareil dans le stockage local (LocalStorage). Aucune donnée n'est transmise à des serveurs externes, sauf si vous activez volontairement la synchronisation Firebase (optionnelle).

3. Utilisation des Données

Les données que vous saisissez sont utilisées uniquement pour :

  • Gérer votre atelier automobile (interventions, véhicules, clients)
  • Générer des documents PDF (factures, carnets d'entretien, rapports)
  • Exporter vos données au format Excel/CSV
  • Afficher des statistiques sur vos interventions et paiements
  • Permettre à vos clients de consulter l'historique de leur véhicule (si vous partagez l'accès)

4. Partage des Données

Aucune donnée n'est partagée avec des tiers. Vos informations restent privées et confidentielles. L'application ne contient :

  • ❌ Aucune publicité
  • ❌ Aucun tracker analytique
  • ❌ Aucun service tiers de collecte de données
  • ❌ Aucune vente de données

4.1 Synchronisation optionnelle Firebase

Si vous activez la synchronisation Firebase (optionnelle), vos données sont synchronisées via les serveurs Google Firebase. Dans ce cas :

  • Les données sont chiffrées en transit (HTTPS/TLS)
  • Vous contrôlez quelles données sont synchronisées
  • Vous pouvez désactiver la synchronisation à tout moment
  • Firebase respecte le RGPD (serveurs en Europe disponibles)

5. Accès Client via QR Code

L'application permet de générer un code QR unique pour chaque véhicule, permettant à vos clients de consulter l'historique de leur véhicule. Dans ce cas :

  • Le client accède uniquement aux données de SON véhicule
  • L'accès est en lecture seule
  • Vous pouvez révoquer l'accès à tout moment
  • Aucune donnée n'est modifiable par le client

6. Sécurité des Données

Nous prenons la sécurité de vos données très au sérieux :

  • Stockage local sécurisé : Données protégées par les mécanismes de sécurité de votre appareil
  • Chiffrement en transit : Si synchronisation activée, connexions HTTPS/TLS
  • Pas de serveur central : Aucun point de défaillance unique
  • Contrôle total : Vous êtes propriétaire de vos données

7. Permissions de l'Application

L'application demande les permissions suivantes :

7.1 Caméra

Pourquoi : Pour prendre des photos des interventions mécaniques.
Utilisation : Les photos sont stockées localement et compressées automatiquement.

7.2 Stockage

Pourquoi : Pour sauvegarder les données localement et exporter les PDF/Excel.
Utilisation : Lecture/écriture des données de l'application uniquement.

7.3 Internet (optionnel)

Pourquoi : Pour la synchronisation Firebase optionnelle.
Utilisation : L'application fonctionne 100% hors ligne si non activée.

8. Vos Droits (RGPD)

Conformément au Règlement Général sur la Protection des Données (RGPD), vous disposez des droits suivants :

  • Droit d'accès : Toutes vos données sont accessibles directement dans l'application
  • Droit de rectification : Vous pouvez modifier toutes vos données à tout moment
  • Droit à l'effacement : Supprimez l'application pour effacer toutes vos données
  • Droit à la portabilité : Exportez vos données en Excel/CSV à tout moment
  • Droit d'opposition : Désactivez la synchronisation optionnelle

9. Conservation des Données

Les données sont conservées tant que vous gardez l'application installée. Vous pouvez :

  • Supprimer des interventions individuellement
  • Supprimer des véhicules complets
  • Désinstaller l'application pour effacer toutes les données locales

10. Données des Mineurs

Tano Evoluzione n'est pas destinée aux mineurs de moins de 18 ans. L'application est conçue pour les professionnels de l'automobile. Nous ne collectons pas sciemment de données concernant des enfants.

11. Cookies et Technologies de Suivi

L'application n'utilise aucun cookie, aucun tracker publicitaire, ni aucune technologie de suivi. Les seules données stockées sont celles que vous saisissez volontairement pour gérer votre atelier.

12. Modifications de cette Politique

Nous pouvons mettre à jour cette politique de confidentialité occasionnellement. En cas de changement significatif, nous vous en informerons via une notification dans l'application. La date de dernière mise à jour est indiquée en haut de cette page.

13. Services Tiers

L'application peut utiliser les services suivants (uniquement si activés) :

  • Firebase (Google) : Synchronisation optionnelle des données (RGPD compliant)
  • jsPDF : Génération de PDF (traitement local, pas de transmission)

14. Juridiction et Conformité

Cette politique de confidentialité est conforme :

  • Au RGPD (Règlement Général sur la Protection des Données - UE)
  • À la loi Informatique et Libertés (France)
  • Aux Politiques de Google Play Store

15. Contact

Pour toute question concernant cette politique de confidentialité ou vos données personnelles, vous pouvez nous contacter :

  • Email : support@tano-evoluzione.com
  • Application : Tano Evoluzione
  • Développeur : Tano Evoluzione

Délai de réponse : Nous nous engageons à répondre à toute demande dans un délai de 48 heures ouvrées.
